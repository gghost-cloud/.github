## About

**GGHOST Cloud** hosts game servers on its own [Pterodactyl](https://pterodactyl.io) panel. Pick a game and a region: the server is set up as soon as you pay where a node has room, or usually within **2 hours** where we add capacity for you (24 hours at most). Plans start at **$3.49/month**, billed monthly.

## Every server includes

- Full file manager and SFTP access
- Backups, schedules and sub-users
- Browser console with start, stop and restart
- Version and build changes, modpack installs
- Support from the people who run the servers, on Discord and by email
